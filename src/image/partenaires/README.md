# Logos des partenaires

Déposez ici les logos des établissements partenaires (formats acceptés : SVG, PNG, JPG, WebP).
Tous les fichiers image de ce dossier sont affichés automatiquement dans le carrousel
« Ils nous font confiance » de la page d'accueil, triés par nom de fichier.

Le nom du fichier sert de texte alternatif : `hopital-nord-franche-comte.svg` devient
« hopital nord franche comte ». Préférez des logos sur fond transparent, d'environ 400 px de large.

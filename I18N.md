# NexSIM — Internationalisation, préférences et cookies

Procédure de remise en service du multilingue (FR / EN / DE) sur le site vitrine,
de la persistance des préférences (thème + langue) par cookies, et de la mise à
jour de la politique de confidentialité.

## 1. Principes retenus

| Sujet | Choix |
|---|---|
| Langues | `fr`, `en`, `de` |
| Langue par défaut | `en` (si la langue de l'hôte n'est pas disponible) |
| Détection | `?lang=xx` → cookie `nexsim_lang` → en-tête `Accept-Language` → `en` |
| Persistance | Cookies `nexsim_lang` et `nexsim_theme`, 1 an, `SameSite=Lax`, `path=/` |
| Consentement | Aucun bandeau : cookies de préférence exprimée par l'utilisateur, exemptés (CNIL / art. 82 LIL) |
| Rendu | 100 % serveur (PHP), aucun flash de langue ni de thème |
| Fallback de clé | Une clé absente d'une langue retombe sur l'anglais |

## 2. Arborescence

```
src/
├── includes/
│   ├── bootstrap.php   # point d'entrée unique inclus par chaque page
│   ├── cookies.php     # lecture/écriture des cookies de préférence
│   └── i18n.php        # négociation de langue, chargement du dictionnaire, t()/e()
├── lang/
│   ├── fr.php          # dictionnaire français
│   ├── en.php          # dictionnaire anglais (= fallback)
│   └── de.php          # dictionnaire allemand
└── …
```

## 3. Étapes d'implémentation

1. **Dictionnaires** — réécriture complète de `src/lang/{fr,en,de}.php` à partir des
   textes en dur dans `index.php`, les partials, les pages légales et
   `scripts/animations.js`. Clés plates en notation pointée, regroupées par section :
   **191 clés, strictement identiques dans les trois langues**.
2. **Sélecteur de langue** — bloc `.lang-switcher` dans le pied de page : trois liens
   `?lang=xx` (fonctionnels sans JavaScript), `hreflang`, `lang` et `aria-current`
   renseignés, libellé accessible dans la langue courante.
3. **Cookies** — `src/includes/cookies.php` centralise lecture/écriture ; le thème est
   appliqué côté serveur dès la balise `<html>` (plus de flash) et réécrit côté client
   par le bouton de bascule ; migration transparente depuis l'ancien `localStorage`.
4. **Politique de confidentialité** — section « cookies » réécrite (tableau des deux
   cookies : nom, finalité, durée, base légale), ajout du traitement de l'en-tête
   `Accept-Language`, durées de conservation mises à jour, le tout traduit.
5. **Détection automatique** — `Accept-Language` analysé avec ses facteurs `q`, repli
   sur l'anglais ; en-têtes `Vary: Accept-Language, Cookie` et `Content-Language`
   envoyés pour les caches et les robots.

### Points d'attention

- Les liens internes ne portent **pas** de `?lang=` : la langue suit le cookie.
  Le paramètre ne sert qu'à changer de langue et aux URL canoniques par langue.
- `en.php` est le dictionnaire de repli : toute clé qui y manque s'affichera telle
  quelle (le nom de la clé) — c'est le seul fichier à tenir complet en priorité.
- Les pages légales restent juridiquement françaises ; les versions EN et DE
  affichent un avertissement de traduction (`legal.translation_notice`).

## 4. Utilisation dans les gabarits

```php
require_once __DIR__ . '/includes/bootstrap.php';

echo t('hero.title');          // chaîne traduite, HTML simple autorisé (<strong>, <br>)
echo e('nav.aria.main');       // même chose, échappée : à utiliser dans les attributs
echo t('lusim.deploy', ['minutes' => 5]);   // remplacement de {minutes}
nexsim_lang();                 // 'fr' | 'en' | 'de'
nexsim_lang_url('de');         // URL courante avec ?lang=de
```

Règle : `t()` pour le contenu (le HTML des dictionnaires est volontaire),
`e()` dans tout attribut HTML.

## 5. Ajouter une langue

1. Copier `src/lang/en.php` vers `src/lang/xx.php` et traduire.
2. Ajouter l'entrée dans `NEXSIM_LANGS` (`src/includes/i18n.php`) : libellé natif,
   code `hreflang`, locale Open Graph.
3. Ajouter les `<xhtml:link>` correspondants dans `src/sitemap.xml`.

## 6. Vérification

```bash
php -S 127.0.0.1:8091 -t src
```

| Cas | Attendu | Vérifié |
|---|---|---|
| `Accept-Language: fr-FR,fr;q=0.9` | `fr` | ✅ |
| `Accept-Language: de-DE,de;q=0.9` | `de` | ✅ |
| `Accept-Language: fr-CH` (sous-balise) | `fr` | ✅ |
| `Accept-Language: en;q=0.2, de;q=0.9` (facteurs q) | `de` | ✅ |
| `Accept-Language: it-IT` (indisponible) | `en` | ✅ |
| aucun en-tête | `en` | ✅ |
| `?lang=de` avec `Accept-Language: fr` | `de` + `Set-Cookie` | ✅ |
| `?lang=xx` (invalide) | ignoré, retour à la négociation | ✅ |
| cookie `nexsim_lang=de` vs en-tête `fr` | `de` | ✅ |
| bascule de thème puis navigation | thème conservé, sans flash | ✅ |
| panneau des modules 3D (JavaScript) | suit la langue de la page | ✅ |
| pied de page à 375 px | pas de débordement horizontal | ✅ |
